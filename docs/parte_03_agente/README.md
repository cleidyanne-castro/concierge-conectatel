# Parte 3: Agente Concierge

Esta pasta documenta o agente responsável por interpretar perguntas, consultar
a base de conhecimento e produzir respostas fundamentadas.

## Responsabilidades

- integrar o agente ao modelo aprovado.
- usar fontes recuperadas com vigência validada.
- apresentar respostas com citação de fonte.
- aplicar limiar de confiança.
- integrar resposta, decisão e rastreabilidade ao fluxo ponta a ponta.

## Integração

Os módulos de implementação estão em `src/parte_03_agente/`. A execução deve
consumir os contratos da Parte 2 e registrar a decisão para as Partes 4 e 5.
